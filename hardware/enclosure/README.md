# Prototype Enclosure

These STL files are the revised V2 prototype:

- `page_turner_front_fit_v2.stl`
- `page_turner_back_fit_v2.stl`
- `page_turner_button_coupon_v2.stl`

Units are millimetres; import at 100% scale.

The parts have not yet been physically fit-verified. Print the small coupon
before committing to the full enclosure. The intended print orientation is with
each part's largest flat exterior face on the build plate. Ask the slicer to
check for non-manifold geometry before printing.
